# 原版片段声像：稳定增益与启动平滑

本轮取得17个完成的原版导出，建立了可移植的完整PCM基准，尚未实现GT Studio声像DSP。此前按普通左右平衡理解AudioPan的假设不成立；只看片段中段也会漏掉约前75毫秒内的参数启动过程。当前产品没有声像控件，MCP声像设置也仍未接入。

## 原版操作与证据

只操作专用`REA Reference · 2026-10-21`，输入均为自有两秒48kHz/S16 WAV：单声道恒定4096，双声道左4096/右8192。时间线24fps，0至48帧，AudioVolume=0dB、AudioPanEnabled=true，默认双声道总线。原版stub声明AudioPan范围-100至100；原版检查器也实际回显`100.0 声像`，没有把大数值误当作另一个参数单位。

`probe_resolve_audio_pan.lua`设置单声道9个位置（-100/-75/-50/-25/0/25/50/75/100）和双声道5个位置（-100/-50/0/50/100）。14个原始任务均Complete/100%，最终rendering=false。实际输出由解码器确认音频专用MOV、48kHz双声道pcm_s24le。

`probe_resolve_audio_pan32.lua`追加单声道25/50/100三个位置，明确请求AudioBitDepth=32。3个原始任务也均Complete/100%，解码器实际确认pcm_s32le，不能只凭设置返回成功判断32位格式。其余轨道和用户工程未改动。创建脚本、精确任务状态脚本均保留在scripts目录。

保存标记及SQLite一致性backup快照保留运行记录；REA CLI对24位实验快照的身份、表结构与3行采样给出Evidence `ev_0af04e8e3cd315bd374a255f66738ea9604b76dfe01d0d2f79d5ac05649082e7`。范围是快照检查，不证明DSP实现。行为结论来自原版读回及17个实际PCM流。

## 稳定区间观察

同一输入声道上的稳定幅度比可换算为下列分贝。表中的值来自完整流中5000至尾部72样本前恒定不变的区间，分贝显示取一位；完整数字和PCM见夹具。

| 单声道声像 | 左声道增益dB | 右声道增益dB |
|---:|---:|---:|
| -100 | +6.0 | -6.0 |
| -75 | +4.9 | -6.0 |
| -50 | +3.5 | -6.0 |
| -25 | +1.9 | -2.5 |
| 0 | 0.0 | 0.0 |
| 25 | -2.5 | +1.9 |
| 50 | -6.0 | +3.5 |
| 75 | -6.0 | +4.9 |
| 100 | -6.0 | +6.0 |

双声道选定位置分别作用在左右输入上：右输入为左输入两倍时，右输出保持相应两倍关系。尚不能由DC推断一般声像、声道串混或其他布局都相同。

这些点与`1±pan/100`换算dB、量化到0.1dB并限制在±6dB的模型一致，但这仍是有限点上的推断，未确立连续参数算法。特别是端点并非单侧静音，不应替换成普通balance/equal-power公式。

## 启动过程与未通过的模型

除既有72样本自动片段边缘外，非零声像在样本72至128仍是单位增益，从样本129才开始改变。以+100单声道为例，左声道到样本3218才完全稳定，右声道到样本3554才稳定。第1000样本左右幅度比约0.587630和1.822786，不能当作最终系数。

32位输出揭示更多低位：+100左稳定系数0.5011872053146362、右1.9952622652053833。将3组32位完整流最近偶数量化为24位，与对应24位原版输出全部逐字节一致，0个差异标量。这验证了两批精度与既有PCM24量化证据的关系。

分析脚本保留一个明确失败的假设：用实测稳定值为目标，前128样本单位增益，之后双精度一阶递推alpha=0.00200801，剩余差小于0.001时直接到目标。3组/6声道的启动比较仍各有408至807个差异样本，最大差异约268448至272928个S32载体单位。部分大差异来自停止平滑的边界，并非可由放宽一位容差消除。该系数只是近似拟合，不用于生产渲染，也不宣称是原版系数。

## 可复跑的材料

`research/audio-pan-fixtures.json`仅含17组自有信号的完整压缩PCM、摘要、输入定义、任务状态和属性读回，不包含原版数据库、二进制、音乐或用户媒体。约370KiB。

运行`.venv/bin/python scripts/analyze_native_audio_pan.py`可离线校验完整PCM摘要、稳定区间、启动位置、32至24位全流关系以及失败模型的残差。加`--capture`时才读取本机已完成的原版任务材料重新生成夹具，并验证源WAV的每个样本确实是上述自有恒定信号。默认分析不需要原版安装、REA、FFmpeg或网络。

本轮改变的是证据和下一步DSP约束，产品声像功能仍未完成。还需确定真实平滑系数、运算精度与终止规则，并验证正弦/音乐、片段非零起点、连续连接、音量组合、自动化和其他采样率/布局，再接入工程、检查器与MCP。既有287项产品回归不能作为声像功能通过的证据。
