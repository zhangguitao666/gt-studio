# GT Studio 原版媒体对照

完整功能相同的目标仍未实现。这轮比较十条原版参考时间线与独立 MCP 重建输出，开始验证结构一致之后的媒体结果。

## 输入与原版输出

使用自制 `workspace/demo-media/motion.mp4`。原版七组变速和三组播放头定格案例来自已保存的调用读回。原版在专用参考项目中导出十个 640×360、24fps、ProRes HQ/PCM24 MOV；`native-render-status.json` 保留十个真实任务 ID、参数及全部 Complete 状态。

最初请求的 320×180 输出被原版钳制为 320×256，不能当作所请求尺寸已实现。第二批使用有效的 640×360，第一批保留为诊断材料。脚本以实际编码器 ID `ProRes422HQ` 调用 API，字典中的显示名称不能直接作为 ID。

原版任务和运行时载荷保存在 `evidence/reference-runtime-archive.sqlite`。REA 原始字段检查为 `evidence/resolve-runtime-archive-markers.json`，Evidence ID `ev_2fa61bbaaa32bea338230110e6fe37872e2064ae7f3b1b804f14620d996ef5ef`。派生提取记录源 blob、解压数据、载荷的摘要与字节偏移；未推断外围私有二进制结构。

## 比较范围

`scripts/compare_native_retime_media.py` 通过真实 stdio MCP 创建项目和执行编辑、保存、导出。当前主报告 `native-media-comparison.json` 使用独立输出 640×360，与原版输出尺寸相同；两者再统一解码为 320×180 RGB24/24fps 进行有界测量。原始帧数与归一化帧数分别记录，所有输入输出文件都有摘要。

十组原始视频帧数均一致：大多数 94 帧，200% 波纹案例 70 帧，50% 波纹案例 141 帧。运动图案的估计源帧身份序列也逐帧一致，包括倒放、半速重复、快放、空隙和定格；身份估计保留第二候选误差，属于启发式测量。

相同导出尺寸后的 RGB 平均绝对误差约为 0.77–0.87/255；只有快放后空隙的 11 个纯黑帧完全相同。其余帧不是字节一致。色彩精度、色彩标签、编码器、色度和缩放路径仍有差异，不能据此宣称画面完全相同。此前独立输出 320×180 的报告单独保留为 `native-media-comparison-320.json`，避免把两种测量条件混为一谈。

## 音频校正

源素材为单声道。实测原版左右声道复制源音量，旧独立链路先由 FFmpeg 默认单声道转立体声降低约 3.01dB，随后限制器自动增益又放大，合并后为源信号的约 0.7443 倍。原版、源与旧独立输出的 PCM 读回和计算记录在 `native-audio-channel-diagnostic.json`。

现对已检测的单声道显式复制左右声道，并关闭限制器自动电平补偿。单声道与立体声回归验证低于限制阈值的 PCM 保持单位增益；旧项目缺少声道信息时只读探测素材，不悄悄改写项目状态。基准 RMS 从旧值约 2154 改为约 2894，原版约 2893。

这只修正了已查明的默认增益问题。原版与独立音频仍不是逐样本相同；变速音频的相关性仍有明显差异，FFmpeg atempo 与原版算法、相位及精确时间处理尚未对齐。原版过载限制、总线、插件和完整 Fairlight 行为也未验证。

修复前报告及独立媒体副本保留在 `native-media-comparison-before-audio-fix.json` 所指路径，便于复查前后差异。所有报告保持 `full_resolve_parity=false`。

## 后续精度更新

高精度中间格式升级的独立新报告为native-media-comparison-precision.json，旧报告及媒体保持。十组MSE均下降30.25%–32.00%，RGB MAE降至0.6236–0.7049；音频PCM保持原独立结果。完整实验、alpha修复及限制见COLOR-PRECISION.md。原版像素/音频残差、标签和完整色彩管理差异仍在。
