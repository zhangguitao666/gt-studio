# Fusion 节点检查点与差异定位

此文记录预乘修正前的检查点阶段，表中数值是当时的历史测量。当前算法和后续受控对照见 [FUSION-ASSOCIATED-ALPHA.md](FUSION-ASSOCIATED-ALPHA.md)。

本阶段加入独立节点 RGBA16 PNG 导出，以区分节点计算、片段处理和时间线合成的差异。没有改变当前 Alpha 算法，也没有将五节点子集认定为原版等效。

## 使用

MCP：`render_fusion_frame(clip_id, output, node_id?, frame=0)`。output 必须为 PNG；frame 是变速后、从0开始的片段内帧。省略节点时保存指定 MediaOut。可先用 `get_fusion_graph` 获取节点 ID。

桌面：在 Fusion 页面选择视频片段，单击节点，滚动节点参数面板到底部，点击 **Save selected node PNG…**。当前播放头位于片段内时使用对应局部帧，否则使用第0帧。

输出采用项目画布尺寸，位置在片段调色、变换、透明度和时间线合成之前。源选择与整段渲染共用变速/倒放/定格逻辑。未连接的无关分支不影响导出；所选分支必须完整。纯生成器分支不用打开离线源。导出不修改工程、撤销或重做，可用于锁定轨道。临时文件原子替换，失败保留旧输出，禁止覆盖工程及源媒体。

## 实测

`scripts/compare_fusion_checkpoints.py` 通过已配置MCP启动器及私有服务，校验原先六组工程和原版媒体摘要，分别导出 MediaOut 和中间节点。每组使用640×360第0帧，与原版 AlphaMode=1 的ProRes4444导出经同一FFmpeg解码到RGBA16后比较。数据见 `fusion-checkpoint-comparison.json`。下表为全帧逐通道绝对误差均值除以257，换算到0..255尺度，便于阅读；不是改变颜色或拟合后得到的指标。

| 案例 | R MAE | G MAE | B MAE | A MAE |
| --- | ---: | ---: | ---: | ---: |
| 半透明背景 | 0 | 0.0506 | 0.8288 | 0.5019 |
| 共享背景分支 | 0.1206 | 0.0506 | 0.1595 | 0 |
| 媒体恒等路径 | 3.1089 | 0.0078 | 0 | 0.0584 |
| 半混合Merge | 6.5973 | 0.0082 | 12.3073 | 0.0467 |
| 90度旋转 | 0.0171 | 0.0072 | 0.1716 | 0.1565 |
| 右上缩小变换 | 0.0299 | 0.0124 | 0.2465 | 0.1041 |

半透明蓝背景内部原版导出为 `[0,13,65322,32896]`，独立节点为 `[0,0,65535,32767]`；共享分支 Alpha 均49344。节点内部RGB接近，但原先无Alpha整段输出的蓝为原版253、独立125。该观察把后续排查指向节点之后的透明度/时间线处理；仍需受控下层和导出设置对照，不能仅据此决定忽略Alpha。

Merge 内部样点原版 `[52736,0,29083,65520]`，独立 `[48390,2,16359,65532]`，说明其差异在节点输出阶段已存在。恒等媒体路径也有红通道残差；旋转/变换的边缘采样不同。不能把这些差异全部归结于主时间线。

原版参照是经过颜色与编码处理的导出文件，并非原版内部缓冲区。六组静态首帧不能证明动态图像、其他颜色/透明度、参数范围或完整算法一致。PNG采用16位存储，而Transform/Merge仍显式经过8位RGB处理边界。

## 验证与部署

新增12项引擎检查，覆盖指定节点、透明度、局部帧、锁定/离线生成器、不完整旁支、工程/历史不变、参数拒绝、保护输入文件、失败保留输出，以及编码帧号素材的正常/2倍/倒放源帧选择。Qt→HTTP已有用例新增真实保存按钮调用。完整224项通过，见 `test-results-fusion-checkpoints.xml`。

主服务和桌面已重启加载新版，先保存当前演示工程并确认无活动渲染，随后重开同一工程；内存撤销历史随重启清空。原生CUA实际选择Transform并通过保存对话框生成PNG，已配置MCP对同一节点/帧再次导出，文件逐字节相同且工程与保存文件一致。记录 `fusion-checkpoint-live-verification.json`、`fusion-checkpoint-native.png` 和对应AX文本。主窗口保持Fusion页、第0帧暂停。

下一步：建立透明/不透明下层、Alpha/Blend梯度及明确颜色设置的原版对照，再分别校准主合成和Merge；之后扩充节点、关键帧、色管及其余功能。完整Resolve一致性目标仍未达到。
